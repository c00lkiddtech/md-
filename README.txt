Meowdoku (web port) - personal copy built from your own app.

Play: double-click index.html. No server needed. Use the mouse: click = tap, double-click = double-tap.
No ads: rewarded-ad bonuses are granted directly; there are no pop-up ads or banners.
Purchases, sign-in and cloud sync don't work in this version.

Don't share this folder: it contains the game's own code, art and sound.
